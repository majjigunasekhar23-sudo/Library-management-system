# Library Management System

## Project Description
The Library Management System is a C++ based application designed to manage books and simplify common library operations. The system uses Object-Oriented Programming concepts and file handling to store and manage book records efficiently.

## Key Features
- Add new books with Book ID, title, and author details.
- Display all available books and their current status.
- Search for books by title or author.
- Issue books to library users.
- Return previously issued books.
- Store book records permanently using file handling.

## Technologies Used
- **Programming Language:** C++
- **Concepts:** Classes, Objects, Functions, Arrays, Conditional Statements, Loops, and File Handling.

## Expected Outcome
The application provides a simple and user-friendly way to manage library books. It allows users to add, search, issue, and return books while maintaining book records even after the program is closed.

## Conclusion
This project demonstrates the practical use of C++ Object-Oriented Programming and file handling concepts to develop a basic real-world Library Management System.
